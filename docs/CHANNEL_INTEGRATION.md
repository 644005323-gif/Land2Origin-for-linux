# Channel Integration

WeChatWatcher is the first channel adapter. Its deterministic intent layer
selects only a uniquely evidenced electrochemistry workflow. The bridge then
injects `land2origin.integration.codex_handoff()` into the Codex turn.

Codex must ask for missing parameters, show a compact job summary, and wait for
explicit confirmation. It writes a schema 1.0 job and invokes the allow-listed
Land2Origin CLI. On success it emits one `codex-weixin-actions` block containing
the archived PNG as an image and OPJU as a file. The user receives native
WeChat attachments, never a local filesystem address.

Future channels such as Xianyu should produce the same order and file events:
lead/session -> SKU/quote -> source collection -> parameter confirmation ->
job execution -> quality check -> delivery -> after-sales. A channel adapter
must not call Origin directly or decide scientific parameters.
